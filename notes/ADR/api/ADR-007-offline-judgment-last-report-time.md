# ADR-007：离线判定用「最后上报时间 + 阈值」
- 问题：如何判定设备离线，不加额外保活协议？
- 可选方案：A. 专用心跳 topic；B. 最后上报时间 + 阈值；C. MQTT 连接状态。
- 决定：B——零侵入；**在线判定以「云端接收时间」为准**（（2026-10-01 修订）原「测量数据时间戳」在补发历史 / 网关时钟偏差 / 死区稀疏下会误判离线）；阈值可配置。
- ⚠️ 载荷墙：离线阈值统一配置，且应 ≥ 网关切点心跳间隔（`Collection:DeadbandHeartbeatMs`，否则值稳定设备在两次心跳之间恒判离线）；LastSeenAt 以云端接收时间为准；测量源时间戳仅用于数据新鲜度展示（`LatestValue.Timestamp`）；面板灰显由质量/在线状态驱动，不误杀 quality=Good 的数据。
