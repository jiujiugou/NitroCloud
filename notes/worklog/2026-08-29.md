## 已完成：Dashboard 图表报 addColorStop rgba(NaN,...)（前端 bug）
### 三问
- 为什么做：大屏实时曲线绘制抛 `Failed to execute 'addColorStop' ... rgba(NaN, NaN, NaN, 0.18)`，Dashboard 图表报错。
- 验收标准：`var(--accent)` 输入解析为实际色值，任意非法输入不再产生 NaN，build（vue-tsc + vite）通过。
- 不做会怎样：大屏图表持续报错，且是"颜色解析"而非数据问题，误导排查方向。
### 根因
- `DashboardView.vue` 把 `:accent="'var(--accent)'"`（CSS 变量引用字面量）传给 `RealtimeChart`。
- `RealtimeChart.vue` 的 `hexA()` 直接对字符串做 `parseInt(full.slice(0,2),16)`：`'var(--accent)'` → `parseInt('va',16)=NaN`、`parseInt('r(',16)=NaN`、`parseInt('--',16)=NaN` → 输出 `rgba(NaN, NaN, NaN, 0.18)`。
- canvas 的 `addColorStop` 无法解析 CSS `var()`（只有 CSS 引擎能解析变量），也解析不了 NaN → 抛 SyntaxError。数据链路（`toNum` + `filter(p=>p.value!==null)`）已验证无 NaN 进入曲线，与本次无关。
